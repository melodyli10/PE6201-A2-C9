# Supporting documents

Working evidence and reasoning behind specific deliverables — tool-set scoring, dependency
rules, descriptor rewrites, and similar analysis that the brief asks to be "written down"
or kept "in the repository" without naming a required file or format.

This is separate from `docs/`, which holds the deliverables the brief names explicitly
(`D0_why_an_agent.md`) and reference material shipped with the assignment
(`ADDING_EXTRA_CASES.md`).

Anyone on the team can add a doc here for the piece they're working on. One file per
deliverable, named after it, so it's obvious at a glance what's covered:

| File | Deliverable |
|---|---|
| `D2a_tool_set.md` | D2(a) — the tool-set scoring table and reasoning |
| `D2c_dependency_rule.md` | D2(c) — the dependency rule and the sequential-vs-parallel measurement |

These files are evidence, not the report. The report (Section 2, "The tool layer") argues
from what's written here — it shouldn't repeat it in full.
